# Documentação do Projeto Aurora

Esta pasta reúne os documentos institucionais e materiais de apoio desenvolvidos para o Projeto Aurora.

## Conteúdo

### Projeto_Aurora_Documentacao.pdf

Documento institucional contendo:

- Contextualização sobre violência patrimonial;
- Rede de apoio e proteção;
- Modelo conceitual de crédito subsidiado;
- Fluxo de atendimento;
- Jornada da usuária;
- Referências.

### Modelo_Conceitual_Credito01.pdf

Detalhamento da proposta de crédito subsidiado para mulheres em situação de violência patrimonial: valores, taxa de juros, carência, prazos, garantias (Fundo Garantidor do Governo), fluxo de tratamento em caso de inadimplência e os ganhos para banco e governo ao participar do programa.

### Arquitetura_Magalu_Cloud.pdf

Documentação técnica da infraestrutura do Projeto Aurora na Magalu Cloud: papel de cada componente (VM do Ollama Phi-3, MKS, Kafka self-hosted, Object Storage, VPC e Turia IAM) e como eles se conectam no fluxo de dados, do evento anonimizado enviado pelo banco até a resposta gerada pelo modelo.

## Objetivo

Centralizar a documentação do Projeto Aurora e facilitar futuras atualizações pela equipe.
